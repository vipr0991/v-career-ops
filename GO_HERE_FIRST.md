## 🚀 START IN 3 STEPS

### Step 1: Open Terminal/Command Prompt

**Windows:** Press Windows key → type `cmd` → Press Enter

**Mac:** Press Cmd+Space → type `terminal` → Press Enter

**Linux:** Ctrl+Alt+T

---

### Step 2: Run Backend API

**Copy and paste this command:**

```bash
cd career-ops && python run_api.py
```

**Wait for this message:**
```
Uvicorn running on http://0.0.0.0:5000
```

✅ **DO NOT CLOSE THIS WINDOW**

---

### Step 3: Open ANOTHER Terminal and Run Frontend

**Open a NEW terminal window (keep first one open!)**

**Copy and paste this command:**

```bash
cd career-ops && node run_frontend.js
```

**Wait for this message:**
```
Local:   http://localhost:5173/
```

✅ **DO NOT CLOSE THIS WINDOW EITHER**

---

## ✨ Browser Opens Automatically

## ❌ Not Working?

### "Connection refused" error?

1. Check **Backend Terminal** (first one)
   - Should say: `Uvicorn running on http://0.0.0.0:5000`
   - If error: Read the message and see TROUBLESHOOTING.md

2. Check **Frontend Terminal** (second one)
   - Should say: `Local: http://localhost:5173/`
   - If error: Read the message and see TROUBLESHOOTING.md

3. **Wait 5-10 seconds** then refresh browser (Ctrl+R or Cmd+R)
